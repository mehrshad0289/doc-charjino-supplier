# مستندات زنجیره تأمین شارژینو (Charjino Supplier Documentation)

مخزن رسمی مستندسازی مأموریت شناسایی و جذب تأمین‌کنندگان بین‌المللی محصولات دیجیتال بازی و کنسول برای فروشگاه آنلاین **Charjino** (charjino.ir — ایران).

## هدف پروژه

پیدا کردن زنجیره تأمین واقعی، ارزان، پایدار و قابل اعتماد برای محصولات PlayStation، Xbox و Nintendo (کدهای دیجیتال، گیفت‌کارت، اشتراک‌ها و کلید بازی) با این اولویت‌ها:

1. قیمت خرید بسیار پایین (حداقل ۱۰٪ ارزان‌تر از میانگین بازار ایران برای SKU کاملاً مشابه)
2. امکان پرداخت با ارز دیجیتال (USDT TRC20/BEP20/ERC20، USDC، BTC، LTC)
3. فروش عمده و همکاری B2B / پنل Reseller
4. تحویل خودکار یا قابل اتکای محصول دیجیتال
5. API یا روش عملیاتی سفارش و تحویل

## ساختار مخزن

```
README.md                    → معرفی پروژه و قواعد
PROJECT-STATUS.md            → وضعیت لحظه‌ای پروژه (منبع حقیقت برای ادامه کار)
SUPPLIER-INDEX.md            → فهرست کامل سرنخ‌ها و وضعیت هر تأمین‌کننده
SUPPLIER-COMPARISON.md       → مقایسه و رتبه‌بندی امتیازی تأمین‌کنندگان
CRYPTO-PAYMENT-MATRIX.md     → ماتریس وضعیت پرداخت رمزارزی هر تأمین‌کننده
API-SUPPLIERS.md             → فهرست APIها و نحوه اتصال
IRAN-MARKET-PRICING.md       → قیمت‌های بازار ایران و نرخ ارز مرجع
DECISIONS.md                 → تصمیمات نهایی و پیشنهاد عملیاتی
research-log/                → گزارش مرحله‌ای جلسات تحقیق
suppliers/<supplier-slug>/   → PROFILE.docx، API-DOCUMENTATION.docx،
                               PRICE-COMPARISON.docx، CONTACT-HISTORY.docx، EVIDENCE/
templates/                   → قالب‌های استاندارد Word
```

## قواعد داده

هر داده در مستندات باید یکی از برچسب‌های زیر را داشته باشد:

- `[تأییدشده با منبع]` — با لینک مستقیم به منبع
- `[تأییدشده با پاسخ تأمین‌کننده]`
- `[مشاهده‌شده در وب‌سایت]` — با تاریخ مشاهده
- `[تخمین]`
- `[نیازمند استعلام]`
- `[ردشده]`

ممنوعیت‌ها: قیمت ساختگی، API ساختگی، ادعای پرداخت رمزارزی بدون مدرک، ثبت توکن/رمز در مخزن عمومی، ایجاد سفارش یا تعهد مالی بدون تأیید صاحب کسب‌وکار.

## ادامه کار در جلسه جدید

1. `git pull` بزنید.
2. `PROJECT-STATUS.md` را بخوانید — دقیقاً از «مرحله بعدی» ادامه دهید.
3. `SUPPLIER-INDEX.md` را بررسی کنید تا از تکرار تحقیق جلوگیری شود.
4. تاریخچه Commitها را ببینید.

## وضعیت محرمانگی

هیچ توکن، رمز، API Key یا اطلاعات حساس مشتریان نباید در این مخزن عمومی ذخیره شود. احراز هویت GitHub فقط بیرون از مخزن انجام می‌شود.
