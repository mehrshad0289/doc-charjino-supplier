# doc-charjino-supplier

مخزن مستندات تأمین‌کنندگان جهانی محصولات دیجیتال بازی و کنسول برای **شارژینو (Charjino)** — فروشگاه آنلاین محصولات دیجیتال گیمینگ در ایران (https://charjino.ir).

## هدف پروژه

شناسایی، اعتبارسنجی و مستندسازی مرجع‌های واقعی تأمین (عمده/B2B/Reseller/API) برای:

- PlayStation 4 / PlayStation 5 (اکانت، بازی دیجیتال، PS Plus، PSN Gift Card)
- Xbox One / Series S|X (Game Pass، Gift Card، کد دیجیتال)
- Nintendo Switch / OLED / Switch 2 (eShop، اشتراک آنلاین)
- محصولات مکمل با تقاضای تجاری در بازار ایران

معیارهای اصلی غربالگری: قیمت نهایی خرید < پرداخت رمزارزی < اعتبار و امنیت < موجودی پایدار < شرایط عمده < API < پشتیبانی.


## قوانین مستندسازی (اجباری)

1. هر داده باید یکی از برچسب‌های زیر را داشته باشد:
   `[تأییدشده با منبع]` · `[تأییدشده با پاسخ تأمین‌کننده]` · `[مشاهده‌شده در وب‌سایت]` · `[تخمین]` · `[نیازمند استعلام]` · `[ردشده]`
2. هیچ قیمت، API، ادعای پرداخت رمزارزی یا اعتباری بدون مدرک قابل کلیک ثبت نمی‌شود.
3. وضعیت پرداخت رمزارزی هر تأمین‌کننده دقیقاً در یکی از دسته‌های VERIFIED / PARTIALLY VERIFIED / CONTACT REQUIRED / NOT SUPPORTED / UNKNOWN قرار می‌گیرد.
4. هیچ رمز عبور، API Key، توکن یا اطلاعات محرمانه‌ای در این مخزن عمومی ذخیره نشود. توکن‌های دسترسی Git باید پس از پایان کار باطل شوند.
5. هیچ سفارش، پرداخت یا قراردادی بدون تأیید صاحب کسب‌وکار ایجاد نمی‌شود؛ پیام‌های تجاری فقط آماده ارسال می‌شوند.

## ادامه کار در جلسه جدید

1. `git pull` بزنید.
2. `PROJECT-STATUS.md` و `SUPPLIER-INDEX.md` را بخوانید.
3. آخرین کامیت‌ها را بررسی کنید (`git log --oneline -10`).
4. از آخرین مرحله ناتمام ادامه دهید؛ از تکرار تحقیق ثبت‌شده خودداری کنید.

## سلب مسئولیت حقوقی

برخی محصولات این بازار (اکانت‌های اشتراکی، کدهای ریجن‌لاک‌شده) با شرایط خدمات Sony / Microsoft / Nintendo و قوانین تحریمی آمریکا/اتحادیه اروپا ناسازگاری دارند. ریسک‌های حقوقی و عملیاتی هر تأمین‌کننده در فایل PROFILE همان تأمین‌کننده صریحاً ثبت می‌شود و تصمیم نهایی تجاری با مالک کسب‌وکار است.
